# UltraSoil で磨く

`ultra-soil` スキルを読んでから書く。渡された文章がなければ、直前に話題になっている文を対象にする。

1. 誰が、誰に、どの長さで渡すかを一文で固定する。
2. 事実、数字、固有名詞は残す。意味を別の約束にすり替えない。
3. 磨いた本文を先に出す。解説は本文のあと、二点まで。
4. 候補が複数なら、各候補の末尾に署名を置く。案内文のあとにもう一行は足さない。
5. 最終行は次の一行だけ。記号も訳も付けない。
